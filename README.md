# Manus RTMP Streamer Ultra v3

The most advanced, professional-grade RTMP streaming control panel with real-time data visualization and smart health monitoring.

## 🚀 New in v3 (Advanced Features)

- **Real-time Data Visualization**: Integrated Chart.js for live Bitrate and CPU load tracking.
- **Smart Health Monitoring**: Automatically analyzes stream stability, frame drops, and CPU bottlenecks.
- **Enhanced UI/UX**: A premium, high-performance dashboard with a focus on data clarity.
- **Network Intelligence**: Real-time tracking of network upload speed (TX) and frame drop counts.
- **Session Intelligence**: Detailed history with success/failure outcomes and precise duration tracking.
- **Optimized Engine**: Refined FFmpeg parameters for maximum stability and "Unlimited" quality feel.

## 🛠️ Installation

1. Extract the zip file.
2. Run `npm install` to install dependencies.
3. Run `npm start` to launch the server.
4. Open `http://localhost:3000` in your browser.

## 📦 Key Technologies

- **Backend**: Node.js, Express, Socket.io, Systeminformation
- **Frontend**: Tailwind CSS, Chart.js, FontAwesome
- **Engine**: FFmpeg (CRF 20 Optimization)
